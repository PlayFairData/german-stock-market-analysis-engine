Help — Reading the Mean Reversion Classification

The classification is determined by the Range Position, which is a 0% to 100% scale calculated as: (Price − Bear) / (Bull − Bear).

Valuation Approaches

  • forward fair value (Relative Valuation): It calculates a fair value by multiplying the historical median P/E by an EPS estimate. This assumes the stock should trade at its historical average multiple. It is entirely backward-looking regarding market sentiment.
  • DCF (Absolute Valuation): It calculates intrinsic value by discounting future cash flows based on the time value of money and risk. It is entirely forward-looking and independent of historical market sentiment.

1. BELOW_BEAR (Range Position < 0%)

The stock price is trading below the conservative Bear valuation floor. This implies severe pessimism or a potential value trap. The interpretation explicitly warns: "investigate why; not a confirmed buy."

2. OVERSOLD (0% ≤ Range Position < 20%)

The price is inside the valuation range but heavily skewed toward the Bear floor. It is fundamentally cheap. However, the interpretation differentiates based on price action: if the price is RECOVERING, it is a potential mean-reversion candidate; if FALLING, it advises waiting for stabilisation.

3. DISCOUNT (20% ≤ Range Position < 40%)

The price is below the midpoint (Base/Pivot) but safely inside the lower half of the range. It represents an attractive discount to fair value.

4. FAIR (40% ≤ Range Position < 60%)

The price is trading around the Base pivot (the existing pegv1b fair value). The interpretation is neutral—there is no significant mean-reversion edge.

5. PREMIUM (60% ≤ Range Position < 80%)

The price is above the Base pivot but still inside the upper half of the valuation range. It trades at a premium, meaning the upside vs. fundamentals is limited.

6. OVERBOUGHT (80% ≤ Range Position ≤ 100%)

The price is near or at the optimistic Bull ceiling. The interpretation warns that upside versus fundamentals is limited.

7. ABOVE_BULL (Range Position > 100%)

The stock price has exceeded the optimistic Bull valuation ceiling. The market is pricing in extreme optimism. The interpretation suggests this is a "potential trim candidate."

8. N/A (Range Position is None)

The state cannot be calculated. This occurs when there is insufficient data to compute the Bear/Bull range (e.g., missing EPS path, missing price, or the Bull value is not greater than the Bear value).

Historical Forward Valuation (Hist Fwd)

Forward fair value computed as the 5-year historical median P/E multiple × consensus EPS1e (fair_fwd1). Displayed as percentage deviation relative to the DCF pivot (pegv1b) for comparison as an independent empirical anchor.

HIGH_TV_SHARE — High Terminal Value Share

HIGH_TV_SHARE stands for High Terminal Value Share. It is a quality warning generated by the mean-reversion layer to indicate that the DCF valuation relies too heavily on the terminal value rather than the explicit forecast period.

A high TV share means the valuation is extremely sensitive to the long-term perpetual growth rate (gp) and the discount rate (adjRisk).

DCF Model

While pegv1b is a textbook two-stage DCF that discounts each year's specific EPS individually and adds a terminal value, pegvn is a simplified, blended Discounted Cash Flow (DCF) model.

1. The Core Concept: A Single Blended Growth Rate

Instead of using the actual, year-by-year EPS estimates (which might fluctuate up and down), pegvn takes the starting EPS (EPS0) and the ending EPS (EPS3e) and calculates a single, constant Compound Annual Growth Rate (CAGR) between them.

Formula: cagr = (EPS3e / EPS0) ** (1.0 / n) - 1.0 (where n is the number of years, typically 3).

2. The Calculation

Once it has this single blended CAGR, it passes it to the calcStockPrice function. It calculates the fair value by assuming the stock grows its EPS at that exact same constant percentage every single year, forever, and discounts that smooth, perpetual growth stream back to the present.

It outputs a single fair-value and P/E pair. It does not provide a per-year discounted PV breakdown like pegv1b.

3. Why does the script include it?

pegvn serves as a mathematical cross-check for the pegv1b DCF.

  • If a company's EPS path is smooth and steadily increasing, pegvn and pegv1b will yield very similar fair values.
  • If a company's EPS path is highly volatile (e.g., dips in year 2, spikes in year 3), the blended pegvn will differ significantly from the textbook pegv1b.

4. Role in Mean-Reversion

In the mean-reversion layer, pegvn is used strictly as a consistency check (PEGVN_DISAGREE). If pegvn differs from the pegv1b pivot by more than 10% (MR_PEGVN_TOL = 0.10), it flags a warning. This warns the user that the stock's near-term EPS projections are highly irregular, meaning the textbook DCF (pegv1b) is heavily dependent on getting those specific volatile years right, and a smooth growth assumption wouldn't support the same valuation.
